Jira Assist Privacy Policy

시행일 / Effective date: 2026-11-20

Jira Assist 는 카카오 구성원이 카카오톡 과제(Jira Epic·Story)를 빠짐없이 등록하도록 돕는 크롬 확장 프로그램입니다(크롬 웹스토어 비공개 배포). 정식 Jira Assist 와 베타 Jira Assist (Beta) 는 같은 코드로 만들며, 이 방침은 두 항목에 똑같이 적용됩니다.

Jira Assist is a Chrome extension that helps Kakao employees register KakaoTalk work items (Jira Epics and Stories) with all required fields (distributed privately through the Chrome Web Store). The stable Jira Assist and the beta Jira Assist (Beta) are built from the same code, and this policy applies equally to both.

수집·취급하는 정보 / Data handled

확장 개발자나 별도 서버로 수집·전송하는 개인정보는 없습니다. 확장에는 자체 서버, 분석·광고·오류 수집 도구가 없습니다.

No personal data is collected by or sent to the developer or any separate server. The extension has no server of its own and no analytics, advertising or error-reporting tools.

확장은 과제 등록 화면을 그리기 위해 사용자 본인의 Jira 세션으로 아래 정보를 다룹니다(크롬 웹스토어 신고 분류).

To show the registration screen, the extension handles the following data through the user's own Jira session (Chrome Web Store categories):

  • 개인 식별 정보 — 본인과 다른 사용자의 이름·계정 ID(Reporter·Assignee 검색, 멘션, 템플릿에 저장된 담당자).
    Personally identifiable information — names and account IDs of the user and other users (Reporter/Assignee search, mentions, assignees saved in templates).
  • 웹사이트 콘텐츠(Jira 데이터) — 프로젝트 컴포넌트·버전·스프린트·우선순위·에픽·템플릿 원본 이슈 내용, 본인이 최근 등록한 이슈의 컴포넌트.
    Website content (Jira data) — project components, versions, sprints, priorities, epics, the content of template source issues, and the components of issues the user recently created.
  • 사용자 생성 콘텐츠 — 사용자가 입력한 과제 제목·내용(Jira 이슈로 생성), 개인 템플릿.
    User-generated content — work item titles and descriptions the user enters (created as Jira issues) and personal templates.

다루지 않는 정보: 인증 정보(비밀번호·API 토큰·쿠키를 읽거나 저장하지 않음), 금융·건강 정보, 개인 통신, 위치, 웹 기록, 사용자 활동(입력·클릭 추적 없음).

Not handled: authentication information (the extension does not read or store passwords, API tokens or cookies), financial or health information, personal communications, location, web history, and user activity (no keystroke or click tracking).

읽는 정보 / Data read

  • 과제 등록에 필요한 Jira 데이터: 프로젝트 컴포넌트·버전·스프린트·우선순위·에픽·사용자 검색 결과, 템플릿 원본 이슈 내용, 본인 계정 정보.
    Jira data needed to register a work item: project components, versions, sprints, priorities, epics, user search results, the content of template source issues, and the user's own account information.
  • 최근 등록 이슈의 컴포넌트: 컴포넌트를 추천하려고 본인이 그 프로젝트에 최근 등록한 이슈(최대 50건)의 컴포넌트만 읽습니다. 결과는 패널이 열려 있는 동안 메모리에만 두고 저장하지 않습니다.
    Components of recently created issues: to suggest components, the extension reads only the components of issues the user recently created in that project (up to 50). The result is kept in memory only while the panel is open and is not stored.

쓰는 정보 / Data written

  • 사용자가 [등록]을 눌렀을 때 만드는 Jira 이슈.
    The Jira issue created when the user clicks [등록] (Create).
  • 아래 「보관」의 개인 템플릿.
    Personal templates, described under Data retention below.

이용 목적 / Data usage

  • 위 정보는 Jira 에 과제 이슈를 필수 항목 점검과 함께 등록하는 단일 목적에만 씁니다(선택지 표시, 필수 항목 확인, 컴포넌트 추천, 템플릿 저장·불러오기).
    The data above is used only for the single purpose of creating work item issues in Jira with required-field checks (showing choices, checking required fields, suggesting components, saving and loading templates).
  • 판매하지 않으며, 단일 목적과 무관한 용도나 신용도 판단·대출 목적으로 사용·전송하지 않습니다.
    It is not sold, and it is not used or transferred for purposes unrelated to that single purpose or for determining creditworthiness or lending.

제공·공유 / Data sharing

  • 제3자에게 제공·공유하지 않습니다.
    Data is not provided to or shared with third parties.
  • 확장은 https://kakao.atlassian.net 과만 통신하며, 그 외 어떤 곳으로도 데이터를 보내지 않습니다.
    The extension communicates only with https://kakao.atlassian.net and sends data nowhere else.
  • 통신은 사용자가 브라우저에서 이미 로그인한 본인의 Jira 세션(쿠키)으로 이루어집니다. 확장은 비밀번호·API 토큰을 묻거나 보관하지 않습니다.
    Requests use the Jira session (cookie) the user is already signed in with in the browser. The extension never asks for or keeps passwords or API tokens.

보관 / Data retention

저장하는 정보 / Data stored

  • 개인 템플릿: 사용자의 Jira 계정 속성(user property, 키 jira-assist.templates.v1)에 저장됩니다. 템플릿이 많아 한 속성에 담기지 않으면 jira-assist.templates.v1.<세대>.<번호> 키로 나누어 함께 저장합니다. 사용자 본인의 Jira 계정 안에 보관되며 Jira 의 권한 정책을 따릅니다.
    Personal templates are stored in a property of the user's own Jira account (user property, key jira-assist.templates.v1; when they do not fit in one property they are split across jira-assist.templates.v1.<generation>.<n> keys). They stay inside the user's Jira account and follow Jira's permission policy.
  • 기기 내 사본·캐시·화면 설정: 사용 중인 기기의 chrome.storage.local 에 템플릿 목록의 로컬 사본, 템플릿 원본(양식) 캐시(24시간), 에픽 검색 범위 설정(대상별로 「프로젝트만」 또는 「전체」)이 저장됩니다. 이 데이터는 그 기기 밖으로 나가지 않으며, 확장을 삭제하면 함께 지워집니다.
    On-device copies, cache and view settings: a local copy of the template list, a cache of template source forms (24 hours) and the epic search scope setting (per target, "this project only" or "all") are stored in chrome.storage.local on the device in use. This data never leaves that device and is removed when the extension is uninstalled.
  • 최근 등록 이슈의 컴포넌트(추천용)는 저장하지 않습니다.
    Components of recently created issues (used for suggestions) are not stored.

권한 / Permissions

  • https://kakao.atlassian.net/*: 위 Jira 조회와 이슈 생성, 개인 템플릿 저장
    Reading the Jira data above, creating issues, and saving personal templates.
  • storage: 기기 내 사본·캐시·화면 설정 보관
    Keeping the on-device copies, cache and view settings.
  • sidePanel: 등록 화면 표시
    Showing the registration screen in the side panel.
